How to install

Step 1: Get a launcher
We recommend Prism Launcher, CurseForge or the Modrinth App. Install whichever you like first.
Step 2: Import the modpack
In your launcher, choose Create New Instance or Import, pick the file you downloaded from Releases, and let it build.
Step 3: Give it enough RAM
Open the instance settings and allocate about 4 to 6 GB of RAM so the game doesn't stutter or crash.
Step 4: Join the server
Launch the game, add a server with the address mc.glitching.live, and jump in.

🛠️ Step-by-Step Installation

Step 1: Download a Custom Launcher
We highly recommend using CurseForge, Prism Launcher, or Modrinth App to run this pack cleanly. Download and install your preferred tool setup first.
Step 2: Import the Modpack ZIP
Open your launcher app dashboard. Select "Create New Instance" or "Import Profile", point the file picker directly to the .zip file you downloaded above, and click build.
Step 3: Allocate System RAM Memory
Before hitting play, click on the instance configuration parameters settings. Ensure you have allocated at least 4GB to 6GB of RAM to prevent system client performance drops or crash loops.
